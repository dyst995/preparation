# English practice

Daily work on **phrasing, vocabulary activation, and grammar for technical speaking** — not general textbook English.

## Files

| File | Purpose |
| --- | --- |
| [PROFILE.md](./PROFILE.md) | How to coach me (receptive ≫ spontaneous speaking) |
| [phrase-bank.md](./phrase-bank.md) | Reusable interview / technical phrases to activate |
| `sessions/` | Optional dated notes from practice days |

## How to practice

1. Attach or invoke the skill: **js-interview-english-coach**
2. Either:
   - send a JS study topic (notes) and answer **one interview question at a time**, or
   - ask for a short English drill (rewrite, activate phrases, tighten structure)
3. First attempt can be messy — that is expected
4. Retry the same answer after feedback
5. Ask to **save** useful phrases into `phrase-bank.md` when something sticks

Coach skill path: `.cursor/skills/js-interview-english-coach/SKILL.md`
