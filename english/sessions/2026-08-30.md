## 1. Core phrases (memorize)

| # | Phrase | When to use | Example |
| --- | --- | --- | --- |
| 1 | **I’d suggest...** | Soft recommendation | I’d suggest we wait until Monday. |
| 2 | **Would you mind...?** | Polite request | Would you mind sending that again? |
| 3 | **I’m not sure yet.** | Honest uncertainty | I’m not sure yet — I’ll check. |
| 4 | **I’ll get back to you.** | Need time | I’ll get back to you this afternoon. |
| 5 | **That works for me.** | Agree to a plan | Thursday at 2 — that works for me. |
| 6 | **I’m struggling with...** | Difficulty without sounding weak | I’m struggling with the wording here. |
| 7 | **Just to confirm...** | Avoid misunderstandings | Just to confirm, you need it by Friday? |
| 8 | **Feel free to...** | Give permission politely | Feel free to message me anytime. |
| 9 | **On the other hand...** | Second side of an argument | It’s faster. On the other hand, it’s riskier. |
| 10 | **At the same time...** | Two things true together | I like the idea. At the same time, it’s expensive. |

## 2. Vocabulary for today (12 words)

| Word | Meaning (simple) | Useful sentence |
| --- | --- | --- |
| **suggest** | propose an idea | I suggest we start earlier. |
| **prefer** | like more | I prefer the shorter version. |
| **consider** | think carefully about | We should consider the cost. |
| **assume** | believe without proof | Don’t assume they’ll agree. |
| **expect** | think something will happen | I expect a reply today. |
| **avoid** | stay away from | Avoid sending it twice. |
| **mention** | say briefly | He didn’t mention the delay. |
| **follow up** | check again later | I’ll follow up tomorrow. |
| **postpone** | move to a later time | Can we postpone the call? |
| **worth** | good enough for the effort | It’s worth reading carefully. |
| **rather** | instead / preferably | I’d rather wait. |
| **though** | but (soft) | It’s late, though. |

**Don’t confuse:**
- **expect** = think it will happen  
- **except** = not including  
- **accept** = agree to take

## 3. Softening (hedging) — sound natural, not rude

| Too strong / blunt | Softer |
| --- | --- |
| You are wrong. | **I might be missing something**, but... |
| Do this now. | **Could you** do this when you have a minute? |
| This is bad. | **I’m not sure this is the best option.** |
| I need it today. | **Would it be possible** to have it today? |
| No. | **Not really** / **I’d rather not.** |

---

## 4. Natural upgrades

| Instead of... | Say... |
| --- | --- |
| I want you to send | **Could you send** / **Would you mind sending** |
| Wait me | **Wait for me** |
| I will tell you later | **I’ll get back to you** |
| Confirm me | **Just to confirm...** |
| I don’t know what to choose | **I haven’t decided yet** / **I’m not sure yet** |
| More easy | **Easier** |
