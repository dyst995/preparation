# English

Spoken English for interviews: reusable phrases and short unit lessons. Same folder shape as TypeScript / JavaScript study units.

Coaching profile (how to correct you): [`../../english/PROFILE.md`](../../english/PROFILE.md). Dated session logs stay in [`../../english/sessions/`](../../english/sessions/).

---

## Study units

| # | Folder | Focus |
|---|---|---|
| 1 | [phrases](./1.%20phrases/notes.md) | Interview / technical phrases to activate out loud |

Add the next lesson as `2. topic-name/` with the same files as other tracks:

```
interview-prep/english/2. topic-name/
  notes.md          required — the lesson
  self-test.md      optional
  answers.md        optional
  repetition.md     optional
  flashcards.json   optional (only when you ask for a deck)
```

The notes site picks up a new numbered folder automatically (TypeScript / JavaScript track → **English**).

---

## How to use a unit

1. Read `notes.md`. Say the target lines out loud, not only in your head.
2. Do `self-test.md` with notes closed.
3. Check `answers.md` only after you attempt.
4. Next day: `repetition.md`.

Default spoken shape: **definition → explanation → practical consequence/example**.
