# Phrases — Answers

Model lines. Yours can be shorter; they should be sayable.

## Core recall

1. Definition → explanation → practical consequence/example.
2. “The main difference is…” / “The important distinction is…”
3. “The reason for that is…” / “This is determined by…”
4. “A common example is…”
5. “Let me rephrase that.”
6. “Could you clarify…?”

## Activate

1. “The main difference is `===` does not coerce; `==` does.”
2. “At runtime the types are gone; this is determined by the compiler, not by JavaScript.”
3. “I’m not sure yet.” / “I’ll get back to you.”
4. “Just to confirm: you want the output of the snippet, not a refactor?”
5. “I’d suggest…” / “Would it be possible…?” / “I’m not sure this is the best option.”
6. **expect** — “I expect the request will fail if the token is expired.”
7. **currently** — “We are currently using Hermes in production.” (**actually** = in fact, not “right now.”)

## Compare and contrast

1. “Main difference” is the blunt split. “Important distinction” flags a trap people mix up.
2. “In practice” is what you observe in the product. “At runtime” is specifically engine/time of execution.
