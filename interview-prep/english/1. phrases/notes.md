# Phrases

## What you need to know

These are phrases you already understand. The work is to **say them out loud** in interviews instead of pausing to rebuild the sentence.

Add keepers from coaching sessions under **Session additions**. New full lessons go in a sibling folder (`2. topic-name/`), not here.

Curriculum checklist this unit completes:

- Structure starters for compare / cause / example answers
- Default answer shape: definition → explanation → consequence
- Everyday professional lines (hedge, clarify, rephrase)
- Session keepers (actually vs currently, expect / except / accept)

---

## Structure starters

- The main difference is...
- The important distinction is...
- What happens in practice is...
- This is determined by...
- The reason for that is...
- In this case...
- At runtime...
- From the perspective of...
- This matters because...
- A common example is...

---

## Answer shape

**definition → explanation → practical consequence/example**

Example: “Lexical scope means lookup follows where the function is written. Calling it from somewhere else does not change that. A common example is a nested function still seeing the outer `x` after the outer call has returned.”
