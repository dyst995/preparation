# Phrases — Next-day repetition

## How to use

1. Do **not** open `notes.md` first.
2. Say every item out loud, notes closed.
3. Check `answers.md` only after you finish (or after an item if stuck more than ~2 minutes).
4. Mark `[x]` only if you retrieved it without looking.

Target time: **10–15 minutes**.

## Must retrieve

- [ ] Default answer shape: definition → explanation → consequence/example
- [ ] Two compare starters
- [ ] One “why” starter
- [ ] “Let me rephrase that.”
- [ ] “Could you clarify…?”
- [ ] **actually** vs **currently**
- [ ] **expect** vs **except** vs **accept**
